# Налаштування системи квестів з підтвердженням

## Оновлення бази даних:

### 1. Виконай SQL скрипт в Supabase:

```sql
-- Add requires_verification field to quests table
ALTER TABLE quests ADD COLUMN requires_verification BOOLEAN DEFAULT true;

-- Update existing quests
UPDATE quests SET requires_verification = false WHERE quest_type = 'shop';
UPDATE quests SET requires_verification = true WHERE quest_type IN ('kiss', 'message');

-- Add some new quests that don't require verification
INSERT INTO quests (title, description, quest_type, sandik_reward, is_daily, requires_verification) VALUES
('Відкрий магазин', 'Відкрий магазин Sandy Shop', 'shop', 1, false, false),
('Переглянь квести', 'Переглянь список квестів', 'view', 1, false, false),
('Налаштуй профіль', 'Налаштуй свій профіль', 'profile', 2, false, false);
```

## Як працює система:

### Квести БЕЗ підтвердження (requires_verification = false):

- **"Відкрий магазин"** - автоматично відкриває Sandy Shop
- **"Переглянь квести"** - автоматично виконується при відкритті квестів
- **"Налаштуй профіль"** - автоматично виконується при налаштуванні

### Квести З підтвердженням (requires_verification = true):

- **"Поцілунок для Максима"** - відправляє повідомлення в Telegram
- **"Щоденне бажання"** - відправляє повідомлення в Telegram
- **"Серійний поцілунок"** - відправляє повідомлення в Telegram

## Логіка роботи:

### Для квестів БЕЗ підтвердження:

1. Маша натискає "Виконати ✅"
2. Квест автоматично виконується
3. Маша отримує Sandik монетки
4. Показується повідомлення про успіх

### Для квестів З підтвердженням:

1. Маша натискає "Надіслати поцілунок 💋" або "Надіслати бажання 💖"
2. Система відправляє тобі повідомлення в Telegram
3. Маша перенаправляється в Telegram чат
4. Ти підтверджуєш квест через кнопки в Telegram
5. Маша отримує Sandik монетки

## Переваги:

- ✅ Автоматичні квести - швидко та зручно
- ✅ Квести з підтвердженням - контроль якості
- ✅ Гнучка система - можна налаштовувати для кожного квесту
- ✅ Різні типи кнопок - "Виконати ✅" vs "Надіслати поцілунок 💋"

## Тестування:

1. **Автоматичні квести**: Маша натискає "Виконати ✅" → отримує монетки
2. **Квести з підтвердженням**: Маша натискає "Надіслати поцілунок 💋" → ти отримуєш повідомлення → підтверджуєш → Маша отримує монетки
